# GYA² demos

Three simulated product demos of GYA²: deterministic checks on the AI (run by the AI platform) and on the money (run by the bank).

- `dist/demo1-money.html`: the money check alone
- `dist/demo2-ai.html`: the AI check alone
- `dist/demo3-both.html`: both together (main demo)

Open any file in a browser. Build: `python3 build.py`. Test: `node tests/engine.test.js`.
See `CLAUDE.md` for the rules, layout and framing.
